# 🎓 Undergraduate Programmer/Analyst + Licensed Systems Engineer

As a **Systems Engineer**, work in public and private organizations with IT departments, where you’ll plan, design, and lead systemic and software projects. Examples include commercial enterprises, service industries, government ministries, municipalities, and universities. These organizations rely on skilled professionals to manage their technological needs. 🏢🌐

---

## 🔧 What Im Can Do

### As an **Undergraduate Programmer/Analyst**:
- Collaborate in developing data communication systems and software 🌐  
- Participate in gathering software quality metrics and standards 📊  
- Assist in system implementation, operation, and maintenance processes ⚙️  
- Contribute to research, development, and innovation projects in software engineering 🧪  
- Support process optimization and industry advancements 📈  
- Help design and implement public policies for technological growth 🏛️  

### As a **Licensed Systems Engineer**:
- Design, plan, and develop information systems, data communication systems, and software 🖥️  
- Lead cybersecurity strategies and initiatives 🔒  
- Establish and certify software quality metrics ✅  
- Oversee system implementation, operation, and maintenance 🛠️  
- Plan and execute innovative R&D projects 🚀  
- Advise on optimizing software development processes 🤝  
- Contribute to designing and implementing public policies linked to the tech sector 🌍
