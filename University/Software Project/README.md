## 🌟 Introduction

This project explores key concepts in **Project and Product Management**, focusing on methodologies like **Lean Inception**, **Scrum**, and **Kanban**, as well as tools like **User Stories (US)** and **User Story Mapping (USM)**. The goal is to provide a comprehensive understanding of how to plan, estimate, and execute software projects effectively.

---

## 📚 Topics Covered

The following topics are addressed in this project:

- **Lean Inception**: Creating a product vision, defining scope (Is/Is Not/Does/Does Not), identifying personas, features, and drafting a project charter.
- **Integration Processes**: Developing a **Project Charter** to align stakeholders and define project goals.
- **Scrum and Kanban**: Agile methodologies for managing tasks and workflows.
- **User Stories (US) and User Story Mapping (USM)**: Writing user stories and mapping them to prioritize features.
- **Estimation**: Techniques for estimating releases, MVPs (Minimum Viable Products), and timelines.
- **Scheduling**: Planning sprints and managing project calendars.

---

## 🛠️ Practical Work

The practical work consists of three Excel files and accompanying documentation:

### 1. **Lean Inception**
   - **Product Vision**: A clear vision statement for the project.
   - **Is/Is Not/Does/Does Not**: Defining the scope and boundaries of the project.
   - **Personas**: Identifying target users and their needs.
   - **Features**: Listing key features of the application.
   - **Project Charter**: Aligning stakeholders and setting project goals.

### 2. **User Stories (US) and User Story Mapping (USM)**
   - **18 User Stories**: Functionalities for an Airbnb-style application.
   - **MVP (Up to 12 Features)**: Prioritized features for the Minimum Viable Product.
   - **USM**: Visual mapping of user stories to guide development.

### 3. **Sprint Tracking**
   - **Estimations**: Effort estimations for each user story.
   - **Sprints 1 and 2**: Task breakdown and progress tracking.
   - **Lessons Learned**: Insights and improvements identified during the sprints.
