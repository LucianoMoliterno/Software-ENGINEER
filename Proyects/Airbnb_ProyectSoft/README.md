A complete hotel reservation system. This project allows administrators to manage hotel listings and enables users to browse, book, and review hotels.

## ✨ Features

### Admin Features
- 📝 Create and manage hotel listings
- 📊 View booking statistics
- 🔄 Update room availability

### User Features
- 🔍 Browse available hotels
- 📅 Make reservations with date selection
- ⭐ Rate and review hotels (1-5 star system)
- 📤 Share hotel listings
- 💳 Secure payment processing
- 🖨️ Generate printable booking summaries
